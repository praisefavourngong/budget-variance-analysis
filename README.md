# Departmental Budget Variance Analysis using Excel
A financial analysis in Excel focused on departmental budget utilization and variance tracking between planned and actual expenditures. The analysis used Excel functions such as SUMIF, IF statements, and basic formulas to compute variances and assess spending efficiency. A brief interpretation was provided to explain under-utilization or over-utilized trends across departments.
# Skills Used
Excel Formulas, Budget Variance Analysis, Expense Tracking, Financial Interpretation, Data Organization
# Outcome
This analysis helped identify departments with under-utilized budgets and provided insights into spending efficiency across departments, supporting better financial monitoring and control.
